# N-Body Physics Simulation
Простой, но математически честный симулятор гравитационного взаимодействия N-тел на Python (NumPy). 

Используется для просчета орбит и гравитационных маневров (slingshot effect). В качестве примера закинут Вояджер-1, вылетающий за пределы Солнечной системы с использованием гравитации Юпитера.

## Стек:
- Python 3
- NumPy (векторизация)

*P.S. В планах переписать интегрирование на Рунге-Кутту (RK4) и прикрутить графики на matplotlib.*
